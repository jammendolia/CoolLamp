Support

Help with setup, connections, lighting controls, groups, and lamp updates.

Start in the app

Open Help in CoolLamp for guided setup and plain-language recovery steps. Reading Help does not change your lamp.

Set up a lamp

  1. Plug in the lamp and keep your phone nearby.
  2. Open Lamps, choose Add a lamp, and follow the guide.
  3. When asked, hold the lamp's knob for about six seconds and release when the entire lamp flashes blue.
  4. Allow Bluetooth and Local Network access if your phone asks.

If a lamp is not responding

  • Keep the lamp powered and wait for the app's connection check to finish.
  • For Bluetooth, move closer and disconnect another phone that may already be connected.
  • For home Wi-Fi, confirm the phone is on a network that can reach the lamp.
  • If a change is marked unconfirmed, use the offered Check action before repeating it.
  • Do not factory-reset the lamp merely because a connection is slow.

Updates

Keep the lamp powered while an update is downloading, installing, restarting, and being checked. During a Bluetooth update, keep CoolLamp open and stay near the lamp. If sending stops, let the app check the installed version before trying again.

Report a problem

Use the CoolLamp issue tracker. Include the app version, lamp firmware version, phone model and OS version, what you expected, and the exact message shown. Never post lamp passwords, home Wi-Fi credentials, group codes, private keys, or access tokens.
